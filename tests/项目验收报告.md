# 一、项目概况

## （一）项目基本情况

矿用自救器是煤矿井下作业人员在发生火灾、瓦斯爆炸、煤尘爆炸等突发灾害时的重要安全防护装备，其可靠性不仅取决于产品本身性能，也取决于矿井对设备采购、验收、配备、发放、使用、维护及报废等全过程的管理水平。

本项目针对传统矿用自救器管理过程中存在的设备信息分散、纸质台账工作量大、设备流转过程记录不连续、人员与设备责任关联不清、设备状态难以实时掌握以及风险发现滞后等问题，开展矿用自救器安全保障关键技术研究。

项目以矿用自救器全过程安全保障为研究对象，围绕“一器一档”、人器关联、设备状态管理、风险预警和物联感知等关键技术开展研究，并在兴隆庄煤矿进行现场应用验证。

项目实施方案确定的项目周期为2026年4月至2027年3月。

# 二、项目研究目标及验收依据

## （一）项目总体目标

项目以矿用自救器安全保障为研究对象，建立覆盖自救器**入库、发放、使用、维护、报废**全过程的安全保障技术体系。

通过设备唯一标识、设备状态管理、人员与设备关联、风险预警以及数据分析等技术手段，实现自救器全过程可查询、可追溯、可管控，降低超期服役、漏检漏维、账物不符等管理风险，提升矿井安全装备管理的规范化和精细化水平。

## （二）主要研究任务

本项目主要完成以下五项研究任务：

1. 矿用自救器管理体系与总体架构研究；
2. 自救器“一器一档”管理机制与管理模式研究；
3. 自救器“人—器”绑定与安全责任溯源技术研究；
4. 自救器风险预警机制研究；
5. 物联感知设备集成技术研究。

## （三）验收依据

本项目验收主要依据：

1. 《矿用自救器安全保障关键技术研究》实施方案；
2. 《矿用自救器安全管理规定（试行）》（矿安〔2025〕2号）；
3. 《中华人民共和国安全生产法》；
4. 《中华人民共和国矿山安全法》；
5. 《煤矿安全规程》（2022版）；
6. GB 24502-2023《煤矿用自救器》；
7. GB/T 50518-2020《矿井通风安全装备配置标准》；
8. 项目确定的主要经济技术指标及知识产权指标。

项目围绕设备有效期、维护周期及设备状态等因素建立风险识别和预警机制。

# 九、项目成果创新性分析

## （一）“一器一档”全过程管理

项目以单台自救器为基本管理单元，将设备基础信息、流转信息、维护信息及报废信息进行统一关联，形成贯穿设备生命周期的“一器一档”管理模式。

与传统以纸质台账和分散记录为主的管理方式相比，该模式强化了设备状态连续性和历史记录完整性。

## （二）主动风险预警机制

项目建立基于设备生命周期及状态信息的风险识别机制，将传统的人工检查和事后发现逐步转变为主动预警。

通过提前预警、临界拦截及超期锁定等方式，实现风险管理前置。

## （三）人员与设备责任关联

项目建立人员与设备之间的关联机制，使设备管理过程中的人员、设备和业务操作能够形成对应关系，提高设备责任追溯能力。

## （四）全过程数据分析

项目将设备状态、人员信息及设备流转数据进行关联，为设备状态查询、统计分析、配置管理及后续采购决策提供数据基础。

项目实施方案将上述内容确定为项目关键技术和创新方向。

# 十一、项目应用效果

项目实施后，矿用自救器管理由传统的分散式、人工记录方式向全过程、状态化管理方式转变。

## （一）设备信息管理方面

实现自救器基础信息统一管理，能够查询设备当前状态及历史信息。

## （二）设备流转管理方面

实现自救器主要业务环节的过程记录，减少设备流转过程中信息断层。

## （三）风险管理方面

通过设备有效期、维护周期及状态信息进行风险识别，使风险管理由人工查询逐步向主动预警转变。

## （四）责任管理方面

通过人员与自救器关联，实现设备使用责任的查询和追溯。

## （五）统计分析方面

实现设备相关数据的统计、查询及导出，为日常管理和决策提供数据支撑。

# 十七、验收结论

经项目验收组审查，项目《矿用自救器安全保障关键技术研究》围绕矿用自救器全过程安全保障开展关键技术研究及现场应用验证，完成了项目实施方案确定的主要研究任务。

项目形成了覆盖自救器入库、发放、使用、维护及报废等环节的全过程安全保障技术体系，建立了“一器一档”管理机制、“人—器”关联及责任溯源机制，并形成了基于设备状态和生命周期信息的风险预警机制以及物联感知设备集成应用方案。

经项目资料审查、技术指标测试及现场应用验证，项目主要技术指标达到项目实施方案规定要求，相关研究成果已在兴隆庄煤矿开展现场应用，能够满足矿用自救器规范化、全过程安全保障管理的实际需求。

项目形成的全过程设备管理、风险预警及责任追溯技术，对提高矿用自救器管理规范化、精细化水平具有积极作用，形成的技术成果具备进一步推广应用价值。

经综合评价，项目已完成实施方案规定的主要研究目标和任务，达到项目验收要求。

**验收组同意项目通过验收。**

# 十八、验收专家组意见

验收专家组听取了项目承担单位关于《矿用自救器安全保障关键技术研究》项目实施及成果完成情况的汇报，审阅了项目实施方案、验收报告、技术资料、测试资料及相关证明材料，并对项目研究成果及现场应用情况进行了审查。

经审查，专家组认为：

1. 项目研究目标明确，研究内容与矿用自救器安全保障实际管理需求结合紧密，项目研究工作总体符合实施方案要求；

2. 项目围绕矿用自救器全过程安全保障开展了“一器一档”、人器关联、设备状态管理、风险预警及物联感知等关键技术研究，形成了较为完整的安全保障技术体系；

3. 项目实现了自救器主要业务环节的全过程管理，形成了设备档案、人员关联、状态管理、风险预警及数据统计等技术成果；

4. 经技术指标测试和现场应用验证，项目主要技术指标达到实施方案规定要求，系统能够满足现场实际应用需求；

5. 项目成果已在兴隆庄煤矿开展现场应用，对提高自救器管理效率、规范设备管理流程、强化风险预警和责任追溯具有积极作用；

6. 项目形成的技术成果具有一定创新性和工程应用价值，对同类型矿井开展安全装备全过程规范化管理具有一定推广参考意义。

专家组认为，该项目已完成实施方案确定的主要研究任务和技术指标，项目资料基本齐全，达到验收条件。

**专家组一致同意项目通过验收。**
